# 오늘 하루, 독감 사이에서 — 사용 설명서

## 1. 폴더 구성
```
index.html                 메인 화면
style.css                  전체 스타일
script.js                  게임 로직·데이터
google-apps-script.gs      구글시트 연동 코드(참고용, 구글 시트에 직접 붙여넣어 사용)
assets/                    사용하는 이미지
assets/_unused_originals/  코드에서 쓰지 않는 원본 이미지(참고용, 삭제해도 무방)
```

## 2. GitHub Pages 배포 방법
1. GitHub에 새 저장소를 만듭니다.
2. `index.html`, `style.css`, `script.js`, `assets/` 폴더(내부 이미지 포함)를 저장소에 업로드합니다.
   (`assets/_unused_originals` 폴더는 올리지 않아도 됩니다)
3. 저장소 [Settings] > [Pages] 메뉴에서 배포 브랜치를 지정하면 URL이 발급됩니다.
4. 발급된 URL을 학생들에게 공유하면 바로 접속해서 플레이할 수 있습니다.

## 3. 구글시트 연동 방법
`google-apps-script.gs` 파일 상단의 설치 방법 주석을 따라 진행하면 됩니다. 요약하면:
1. 새 구글 시트 생성 → [확장 프로그램] > [Apps Script]
2. `google-apps-script.gs` 내용 붙여넣고 저장
3. 시트로 돌아가 새로고침 → 상단 메뉴 "감염병예방게임" > "초기설정" 클릭 (헤더 + 예시 데이터 4행 자동 생성)
4. Apps Script 편집기에서 [배포] > [새 배포] > 웹 앱으로 배포 (액세스 권한: 모든 사용자)
5. 발급된 웹 앱 URL을 `script.js` 최상단의 `SHEET_WEBAPP_URL` 값에 붙여넣기

`SHEET_WEBAPP_URL`을 비워두면 구글시트 저장 없이도 게임 자체는 정상 동작합니다(로컬 체험용).

## 4. 이미지 클릭 영역(핫스팟) 관련 참고사항
마스크 고르기, 소독제, 손씻기 포스터의 클릭 가능 영역은 업로드해주신 이미지 속 그림 위치를 기준으로 **좌표를 눈대중으로 지정**한 상태예요(`script.js`의 `hotspots`, `hotspot`, `posterHotspot` 값). 실제 배포 후 확인했을 때 점선 원이 그림과 살짝 어긋나 보이면, 해당 숫자(%)를 조금씩 조정하면 됩니다. 예를 들어 마스크 위치를 왼쪽으로 옮기고 싶으면 `left` 값을 줄이면 됩니다.

## 5. 알려진 제한사항 / 다음에 다듬으면 좋을 부분
- 손씻기 배경 이미지 속 작은 포스터와, 확대 모달에 쓰이는 포스터 이미지의 그림체가 살짝 달라요(디자인 차이는 있지만 기능상 문제는 없어요).
- 현재 흑백 선화 스타일을 그대로 사용했습니다. 색을 입히고 싶으시면 이미지 파일만 컬러 버전으로 교체하면 됩니다(코드 수정 불필요).
- 모바일 iOS Safari에서 이미지 다운로드 버튼을 눌렀을 때 새 탭에서 이미지가 열리는 경우가 있어요. 이 경우 사용자가 이미지를 길게 눌러 "사진에 저장"하면 됩니다.
- 짝꿍의 프로필 아이콘은 제공해주신 이미지에서 원형 부분만 잘라 사용했고, 나머지 채팅 UI(상태바, 말풍선, 입력창 등)는 전부 코드로 구현했습니다.

## 6. 테스트 방법 (로컬)
별도 서버 없이 `index.html`을 브라우저로 바로 열어도 대부분 동작하지만, 일부 브라우저는 보안 정책상 로컬 파일에서 이미지를 불러오지 못할 수 있어요. 문제가 있으면 터미널에서 아래처럼 간단한 로컬 서버를 띄워 확인하시면 됩니다.
```
cd 프로젝트폴더
python3 -m http.server 8000
```
그 다음 브라우저에서 `http://localhost:8000` 접속
